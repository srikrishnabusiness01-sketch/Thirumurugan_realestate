# Thirumurugan Real Estate

> Sovereign land proprietor and direct acreage holdings across Tamil Nadu.

An architectural precision single-page website featuring a technical CAD viewport, continuous scroll verification loop, interactive property showcase, and containerized Docker setup.

---

## Features

- **Architectural Cadastral Viewport**: Real-time coordinate HUD, millimeter rulers, and vector land boundaries.
- **Continuous Scroll Verification Loop**: Step-by-step breakdown of DGPS satellite surveying, 30-year lineage audit, sovereign proprietor conveyance, and revenue patta registration.
- **Micro-Interactions**: Dual-label rolling buttons, marquee metric tickers, and interactive title FAQ accordions.
- **Production Ready**: Bundled with Nginx Alpine in Docker for instant review and deployment.

---

## Quick Start (Docker)

```bash
# Build and run container
docker compose up -d --build

# View in browser
http://localhost:8080

# Stop container
docker compose down
```
