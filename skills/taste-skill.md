# Taste Skill — Premium Visual Quality Control

## Core Philosophy
Every design decision must feel INTENTIONAL and SPECIFIC to this
brand. If a choice could appear on any other website, reject it
and find something more distinctive.

## The 5 Anti-Patterns to Avoid
1. Warm cream background (#F4F1EA) + terracotta accent — too common
2. Near-black + acid-green or vermilion — overused dark theme
3. Rounded cards with soft shadows everywhere — SaaS default look
4. ALL CAPS tracked-out eyebrow labels above every heading
5. Gradient washes used purely as decoration

## Color Rules for Thirumurugan Real Estate
- Primary dark: #0A0A0F (near-black with blue undertone)
- Gold accent: #C9A84C (muted antique gold — NOT bright yellow)
- Secondary gold: #E8D5A3 (light warm gold for text)
- Surface: #111118 (card backgrounds)
- Border: #2A2A38 (subtle borders)
- Text primary: #F0EDE6 (warm off-white)
- Text muted: #8A8799 (muted purple-gray)

## Typography Rules
- Display font: Cormorant Garamond (Google Fonts) — elegant serif
- Body font: Inter or DM Sans — clean readable sans
- NEVER use default system fonts for headings
- Letter spacing on headings: 0.02em to 0.05em only
- Line height body: 1.7, headings: 1.1 to 1.2
- NO sentence in all-caps unless it is a single word label

## Spacing & Layout Rules
- Use generous whitespace — luxury brands breathe
- Section padding: minimum 120px top and bottom on desktop
- Max content width: 1200px centered
- Grid: 12-column, gutters 24px
- Mobile padding: 24px sides minimum

## Motion & Animation Rules
- One hero animation only — do not animate every section
- Scroll reveals: fade + translate Y 30px, duration 0.6s, ease out
- No bounce, no elastic, no spring effects
- Hover transitions: 0.3s ease — subtle, never jumpy
- Respect prefers-reduced-motion always

## Photography & Visual Rules
- Dark overlay on all hero images: rgba(0,0,0,0.45) minimum
- No stock-photo-style bright cheerful images
- Land/property images should feel cinematic and wide
- Avoid white backgrounds on any section

## Quality Checklist Before Output
Before delivering any design, verify:
- [ ] Does it look premium or does it look generic?
- [ ] Is the color palette consistent throughout?
- [ ] Are there more than 3 font sizes? (reduce if yes)
- [ ] Does motion feel intentional or scattered?
- [ ] Would a luxury buyer trust this brand on first view?
- [ ] Is it readable on mobile?
- [ ] Does contrast pass WCAG AA minimum?

## Tone of Brand
Thirumurugan Real Estate = Trust + Legacy + Land Ownership
Not modern-tech-startup. Not flashy-sales-website.
Think: old money, established family, generational land wealth.
Sophisticated. Calm. Authoritative.
